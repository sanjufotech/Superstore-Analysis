Sales Summary Analysis Using SQLite and Python

Project Description

This project demonstrates how to integrate SQL with Python to perform basic sales analysis using a SQLite database. The Superstore sales dataset from Kaggle was imported into SQLite, and SQL queries were executed within Python to extract meaningful business insights such as total revenue and total quantity sold by product category.

The queried data was loaded into Pandas DataFrames for analysis and displayed using Python print statements. A simple bar chart was created using Matplotlib to visualize category-wise revenue, helping identify the highest-performing product categories.

Key Features

* Imported CSV sales data into a SQLite database.
* Connected Python to SQLite using the sqlite3 library.
* Executed SQL aggregation queries using GROUP BY and SUM functions.
* Retrieved query results into Pandas DataFrames.
* Generated sales summaries and revenue insights.
* Created a bar chart visualization using Matplotlib.
* Saved visual outputs for reporting and portfolio purposes.

Technologies Used

* Python
* SQLite
* Pandas
* Matplotlib

 Business Insights

* Identified revenue generated by each product category.
* Analyzed total quantity sold across categories.
* Visualized category performance through charts.
* Demonstrated how SQL and Python can be combined for business reporting and decision-making.
